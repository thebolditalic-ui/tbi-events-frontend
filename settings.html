Reconnect services

Reconnect Facebook

If Facebook posting or commenting stops working (token expired), paste a fresh Facebook user token from the Graph API Explorer here. The system extends it to a permanent Page token automatically — no expiry, nothing to paste into Supabase.

Reconnect Threads

To pull Threads views, likes and replies (account insights), paste a fresh Threads user token minted with the threads_manage_insights permission. Not the app id|secret — a long single-string user token. The system extends it to a long-lived token automatically.

Substack (Notes)

Connect Substack to schedule Notes (short updates) alongside your other channels. Substack has no official API, so this uses your logged-in session cookie. In a browser signed in to Substack, open DevTools → Application → Cookies → substack.com, copy the substack.sid value, and paste it below. It lasts months as long as you stay signed in.
