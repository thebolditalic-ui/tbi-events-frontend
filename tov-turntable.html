The grid

One tile is one meter of floor. Gus is 1.7 m, so he lands a little taller than a tile is wide.

The object

Meshy exports a rigged person at true height. It exports furniture at whatever size it likes. Use Fill footprint for a sofa, Set height for a person.

Slicing is only for tall, free‑standing objects a character can walk both behind and in front of. Needs 4 directions. Anything against a wall does not need it.

The turntable

The finish

Textures get anisotropic filtering automatically, which is what fixes blurry seats and tabletops. The outline is a drawing convention, not a sharpness fix; turn it on if your art has ink lines.
